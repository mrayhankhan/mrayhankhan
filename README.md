### How I like to work

- **Weigh each idea.** I look at overlap with existing work, value to users and the business, dependencies and team capacity.
- **Scope to the outcome.** I keep the first build focused on the results that matter most.
- **Agree what done means.** Work counts once it's on GitHub with real test output, and a person approves what matters.
