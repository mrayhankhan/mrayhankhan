### How I work

- **Check what exists first.** I audited 20 proposed AI agents against the live codebase. 12 duplicated existing work, and 8 were worth building.
- **Cut to the outcome.** I scoped an 11-panel CEO dashboard to 7 AI-led panels, tied to lead generation, content ROI and platform health.
- **A demo is not a launch.** Work counts once it is on GitHub with real test output, and a retrained model goes live only if it beats the baseline.
